How this login flow works

  1. You click a Sign in with… button, which sends you to the identity provider's /authorize endpoint.
  2. You authenticate directly with the provider (this app never sees your password).
  3. The provider redirects back with an authorization code at /login/oauth2/code/{provider}.
  4. Spring Security exchanges that code for an ID token (a signed JWT describing who you are) and, optionally, an access token.
  5. The ID token is validated and its claims (sub, name, email, …) become your Spring Security principal — visible on your profile page.
